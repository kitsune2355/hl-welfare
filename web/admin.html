ผู้ใช้ระบบ

ชื่อผู้ใช้ควรตรงกับบัญชีใน stock_hr — สต็อกใช้ส่งลิงก์เซ็นรับชุดฟอร์มให้ผู้ขอเบิก

Session ที่ใช้งานอยู่

จบ session แล้ว ถ้าเครื่องนั้นเลือก “จดจำฉัน” ไว้จะเข้าใหม่ได้เอง — ใช้ “ออกจากระบบทุกอุปกรณ์” ในแท็บผู้ใช้เพื่อบังคับ

อุปกรณ์ที่ “จดจำฉัน”

refresh token ที่ยังใช้ได้ (หมุนทุกครั้งที่ใช้) — เลิกจดจำแล้วเครื่องนั้นต้องกรอกรหัสผ่านใหม่

ประวัติการเข้าสู่ระบบ

ใบเบิกชุดฟอร์มในสต็อก Uniform

ไปหน้าชุดฟอร์ม

ล้างข้อมูลเก่า

session · refresh token · ประวัติเข้าสู่ระบบ (ไม่ลบบันทึกการใช้งาน) — ตั้งเวลาด้วย backend/bin/cleanup.php

ข้อมูลระบบ

เวอร์ชัน · ค่าตั้งการเข้าสู่ระบบ · จำนวนแถวในตาราง

การเชื่อมต่อสต็อก Uniform

API ของ stock_hr (api/welfare.php) — เซ็นทุกคำขอด้วยกุญแจ HMAC ที่ต้องตรงกับ stock_hr/config_ctrl/welfare_key.php

การเข้าสู่ระบบ

มีผลกับคำขอถัดไปทันที (session ที่เปิดอยู่ใช้ค่าใหม่ด้วย)

การติดตามระบบ

แก้ได้เฉพาะใน backend/config.php
